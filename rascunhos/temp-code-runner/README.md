# Rascunhos do Code Runner

Estes arquivos eram chamados `tempCodeRunnerFile.*` e estavam misturados às aulas/projetos. Foram movidos para cá para reduzir a poluição das pastas de exercícios sem apagar seus conteúdos. Os nomes descrevem sua origem; revise-os antes de reutilizar, pois alguns são trechos incompletos ou dependem de outras classes/variáveis.
